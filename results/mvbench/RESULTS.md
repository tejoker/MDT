# MDT out of sample: results

Generated by `python -m experiments.mvbench.numbers_sheet`. Do not edit by
hand: every number here is computed from the JSONL files in this directory,
so the report cannot drift from the data.

## What this measures

Given a train/test split, which multi-view operator still separates classes on
points that were never in the operator? Every method compared in the MDT paper
is transductive, so all of them get the same treatment: one kernel, one
truncated-SVD embedding at `k = |C|` components, and one Nystrom extension,
obtained by writing each operator as `W = sum_v P_v S_v` and substituting the
test-to-train transition for the leftmost factor. `bench.py --smoke` asserts
that identity to 1e-16 for all nine operator builders before anything is run.

`inductive_ami` is the primary metric: k-means is fitted on the *training*
embedding and applied to the extended test embedding, so it fails unless the
extension lands unseen points in the same coordinate frame. `test_ami` refits
k-means on the test embedding and is the weaker question of whether the
extension has any cluster structure at all.

`MDT case` = inside the MDT operator space (paper Sec. 3.5); a win over those
concerns trajectory choice, not the framework. `native OOS` = inductive by
construction, so no Nystrom step. `PRR` is Eq. 21 against MDT-Rand as a ratio
of means. `MDT W-L` counts datasets on which MDT-Direct beats / loses to that
row; `p_Holm` is a Holm-corrected exact sign test over the family. The
`best-of-6` row is an oracle: it takes the per-cell maximum over the six MDT
variants using test labels, so it is an upper bound rather than a method.

## Reading the result

1. **MDT-Direct beats every published operator-based competitor out of sample**
   (AD, p-AD, ID, MVD, Cr-Diff), and the paper's PRR of 1.08 reproduces on
   unseen points. This holds at train fractions 0.5, 0.7 and 0.9.
2. **It ties SpecRaGE** (Yacobi et al., TMLR 2025) at roughly half the compute,
   and ties DGCCA.
3. **It is statistically indistinguishable from the uniform-constant**
   **trajectory**, which is itself a member of the MDT operator space. That tie
   holds across 22 datasets, 3 train fractions, 2 kernels, 3 sample sizes and 9
   noise levels, and is the single most robust finding here.
4. **The ordering is kernel-conditional.** Under the reference
   implementation's own kernel the margins shrink and only p-AD stays
   significant; see the kernel table in the LaTeX sheet for why (that kernel is
   not scale invariant and reduces high-scale views to the identity operator).
5. **The noise axis shows no advantage for view weighting.** On K-MvMNIST only
   the second view degrades, which is where learned down-weighting should pay;
   MDT minus the uniform mean is -0.001, +0.005, +0.005, -0.009, -0.014 across
   s = 0.1..0.9, every interval covering zero.

## Reproducing

```bash
git clone https://github.com/ChuanbinZhang/Multi-view-datasets ~/.cache/multi-view-datasets
python -m experiments.mvbench.bench --smoke                              # self-check, ~1 min
python -m experiments.mvbench.bench -c experiments/mvbench/config.yml    # main table, ~2 h

# the strongest inductive competitor, on the identical split
git clone https://github.com/shaham-lab/SpecRaGE
python -m experiments.mvbench.specrage_arm --repo ./SpecRaGE

# ablations
python -m experiments.mvbench.bench -c experiments/mvbench/config.yml --split 0.5
python -m experiments.mvbench.bench -c experiments/mvbench/config.yml --kernel reference
python -m experiments.mvbench.bench -c experiments/mvbench/config.yml --ch-target views
python -m experiments.mvbench.bench -c experiments/mvbench/config.yml \
    --datasets k_mvmnist l_mvmnist --noise-factor 0.9

# regenerate this file, the LaTeX tables and the PDF from whatever JSONL is present
python -m experiments.mvbench.numbers_sheet --pdf
```

Every run appends one JSON object per (dataset, seed, method) and records its own
`kernel`, `ch_target`, `noise_factor`, `split_nominal` and `split_effective`, so
rows from different configurations can never be confused. `--resume` skips
(dataset, seed) pairs already present.

## Caveats worth reading before citing

* Absolute AMI is not comparable to the paper's Tab. 4: the kernel differs, the
  protocol is out-of-sample rather than transductive, and training sets are
  capped at 800 rows. Calibration at n = 800/2000/4200 puts the ceiling near
  0.46, not the paper's ~0.72, so the gap is protocol, not sample size.
* The searched MDT variants are evaluated at n <= 800. MDT-Direct needs 100
  objective evaluations per cell, each a full n x n SVD, which is ~100 h for the
  full grid at n = 4200.
* L-Isolet is excluded: its three views are three *different kernels* on one
  feature matrix, and this benchmark controls the kernel. Note also that two of
  its three views are byte-identical in the reference loader (see the
  discrepancy table).
* 8 of the paper's 9 clustering datasets are covered.
